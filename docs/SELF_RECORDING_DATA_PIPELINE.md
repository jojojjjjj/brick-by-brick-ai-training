## 一、先回答你的三个问题

### 问题 1：10 个人能否泛化到 10 万用户？

**简短回答：不够，但可以补救。**

| 维度 | 10 人 vs 10 万用户 | 覆盖情况 |
|------|---------------------|---------|
| 人数 | 10 vs 100,000 | 差距 10,000 倍 |
| 种族/脸型 | 有限 | <1% 覆盖 |
| 摄像头机型 | 少量 | <1% 覆盖 |
| 光照环境 | 录制环境可控 | 5-15% 覆盖 |
| 头部姿态 | 录制时自然分散 | 30-50% 覆盖 |

**直接用 10 人数据训练的准确率：**
- 同设备/同环境：80-88% ✅
- 真实用户（换设备+换环境）：**55-70%** ❌

**补救方案：用户首次校准 + 使用中在线学习**
- 首次使用：30 秒校准（"请看向屏幕中央"）
- 使用中：用无标签数据持续适应
- 最终准确率：72-82% ✅（勉强可用）

**结论：** 10 人数据是起点，不是终点。需要靠个人校准和用户使用中的数据积累来弥补。

---

### 问题 2：非正脸角度的素材能不能用？怎么用？

**简短回答：能用来训练，但需要过滤。**

手机放桌上朝下拍、人脸不在画面中心——这些素材**不是废料**，可以用。

**原理：** 专注度检测不需要完美正面人脸，只需要：
1. 能检测到人脸（哪怕侧一点）
2. 能判断 gaze 方向（看屏幕还是离开）

**数据质量分级：**

| 等级 | 条件 | 能否训练 | 占比 |
|------|------|---------|------|
| **L1 高质量** | 正脸±15°，人脸占比>30% | ✅ 直接用 | ~25-30% |
| **L2 中等质量** | 侧脸 15-30°，占比 15-30% | ✅ 可用 | ~30-35% |
| **L3 边缘质量** | 侧脸 30-45°，占比 10-15% | ⚠️ 可用但有噪声 | ~15-20% |
| **L4 低质量** | 侧脸>45°，占比<10% | ❌ 丢弃 | ~15-20% |

**对 800h 原始视频的估算：**

| | 数量 |
|--|--|
| 原始视频 | 800 小时 |
| 可用视频（置信度≥0.7） | **~324 小时**（约 580 万帧 @ 5fps） |
| 其中高质量 L1+L2 | ~210 小时 |
| 其中边缘 L3 | ~81 小时 |

**简单理解：** 800h 视频中，大约 **40%** 可以用来训练，其他丢弃。

### 问题 3：AI 能不能帮我自动标注，不用我一张张看？

**简短回答：能，但要分两步走，而且必须先验证 AI 的准确率。**

**两步走方案：**

```
第一步：AI 快速初筛（VLM 大模型）
- 用 LLaVA-1.6-7B 多模态大模型
- 逐帧判断"专注还是不专注"
- 处理 14.4 万帧（0.5fps 采样）
- 需要：~24 小时 GPU 时间
- 准确率：~72-78%（不是 100%）

第二步：规则过滤 + 人工抽检
- 用 MediaPipe 检查 gaze 方向（"眼睛看哪"）
- AI 判断 + MediaPipe 规则交叉验证
- 两者一致 → 采纳
- 两者不一致 → 人工抽检（约 20% 的帧）
- 人工需要审核：~2.9 万帧（约 7-15 人天）
```

**为什么不能 100% 靠 AI？**

AI（VLM 大模型）判断专注度有一个根本限制：
- ✅ 能判断：人在看书、手在记笔记、眼睛看向屏幕
- ❌ 不能判断：人是否真的在"认真思考"（发呆 vs 深度思考看起来一样）

**所以 AI 标注是"高质量伪标签"，不是"最终真相"。用它来训练 FocusNet 专注度模型是 ok 的，但要接受有 ~20-25% 的标注是错的。**

## 二、完整数据流水线

### 整体流程图

```
原始录制
(10人, 800h, 30fps)
     ↓
Step 1: 降采样
     ↓
Step 2: MediaPipe 检测
     ↓
Step 3: 数据质量过滤
     ↓
Step 4: VLM 自动标注
     ↓
Step 5: 交叉验证
     ↓
Step 6: 人工抽检
     ↓
Step 7: FocusNet 模型训练
     ↓
最终模型
```

---

### Step 1：降采样

**做什么：** 把 30fps 的视频降低到 0.5fps（每秒半帧）

**为什么：** 800h × 30fps = 8640 万帧，太多了。0.5fps 足够捕捉专注行为（专注行为通常持续 5-30 秒）。

**工具：** FFmpeg（免费开源）

**命令：**
```bash
ffmpeg -i input.mp4 -vf "fps=0.5" output_frames/frame_%06d.jpg
```

**输出：** 14.4 万张图片（800h × 3600s × 0.5fps）

---

### Step 2：MediaPipe 人脸关键点检测

**做什么：** 用 MediaPipe 提取每张图的人脸关键点（468 个点），计算：
- gaze 方向（眼睛看哪）
- 头部姿态（正脸还是侧脸）
- 眨眼频率（EAR 数值）
- 检测置信度（这帧质量好不好）

**工具：** MediaPipe（Google 开源，Python 可用）

**关键代码：**
```python
import mediapipe as mp
mp_face_mesh = mp.solutions.face_mesh

with mp_face_mesh.FaceMesh(...) as face_mesh:
    results = face_mesh.process(image)
    # 提取 468 个关键点
    # 计算 gaze, pose, EAR, 置信度
```

**输出：**
```
frame_000001.jpg: {gaze_pitch: 0.3, gaze_yaw: -0.1, ear: 0.28, confidence: 0.92}
frame_000002.jpg: {gaze_pitch: 0.4, gaze_yaw: 0.2, ear: 0.25, confidence: 0.88}
...
```

---

### Step 3：数据质量过滤

**做什么：** 只保留置信度 ≥ 0.7 的帧

**为什么：** 置信度低的帧（侧脸太严重/光线太暗/检测失败），用了反而让模型学坏。

**过滤结果：**

| | 帧数 | 占比 |
|--|--|--|
| 原始 | 14.4 万帧 | 100% |
| 过滤后（置信度≥0.7） | ~5.8 万帧 | ~40% |

---

### Step 4：VLM 大模型自动标注

**做什么：** 用 LLaVA-1.6-7B 多模态大模型判断每张图是否专注

**模型选择：**
- 模型：LLaVA-1.6-7B-Mistral（INT4 量化版）
- 显存占用：~7GB（RTX 5080 16GB 够用）
- 推理速度：~3.2 FPS（batch=16）

**Prompt 模板：**
```
这张图片中的人物是否在专注学习？
专注特征：目光朝向学习材料/屏幕，身体姿态前倾，无明显分心行为。
不专注特征：目光明显偏离，低头玩手机，与他人交谈。
请回答：专注 / 不专注 / 不确定
```

**处理时间：** 约 18-24 小时（RTX 5080，batch=16）

**输出：**
```
frame_000001.jpg: {label: "专注", confidence: 0.82, reason: "人物正视屏幕"}
frame_000002.jpg: {label: "不专注", confidence: 0.71, reason: "头部明显偏向一侧"}
...
```

---

### Step 5：交叉验证

**做什么：** 把 VLM 判断和 MediaPipe 检测结果交叉对比

| MediaPipe | VLM | → 最终 |
|-----------|-----|--------|
| gaze 正向屏幕 | 专注 | ✅ 采纳 |
| gaze 偏离 | 不专注 | ✅ 采纳 |
| gaze 正向 | VLM 说"不专注" | ⚠️ 人工审核 |
| gaze 偏离 | VLM 说"专注" | ⚠️ 人工审核 |

**不一致率：** 约 20% 的帧需要人工审核

---

### Step 6：人工抽检

**做什么：** 人工审核不一致的帧（~2.9 万帧）

**标注工具：** Label Studio（开源，支持视频标注）

**人工时间估算：**
- 标注速度：约 2000 帧/人天
- 需要：~14.5 人天（3 人约 5 天）

**减少人工的方法——主动学习：**
- 先用 AI 筛选出"最不确定"的帧
- 人工只审核这些
- 可以把需要人工审核的帧从 2.9 万减少到 ~5000 帧
- 人工时间从 14.5 人天减少到 ~2.5 人天

---

### Step 7：FocusNet 模型训练

**做什么：** 用标注好的数据训练专注度检测模型

**模型架构：** MobileNetV3-Small + GRU（约 1.5M 参数，手机端可跑）

**训练设备：** RTX 5080

**训练时间：** 约 30 分钟到 2 小时（取决于数据量）

**量化：** FP32 → INT8（ncnn），部署到 HarmonyOS 手机

## 三、为什么这套方案可行

### 核心逻辑

```
问题：10 人数据不够多样化
答案：个人校准 + 用户使用中学习来弥补

问题：非正脸角度不能用
答案：置信度过滤后 L1+L2+L3 数据完全可用（40% 的原始数据）

问题：3 人团队无法人工标注
答案：VLM 大模型自动标注 + 主动学习筛选 → 人工减少到 2.5-7.5 人天
```

### 为什么 FocusNet 能学到专注度？

关键洞察：**专注度检测需要的不是"认人"，而是"判断 gaze 方向和头部姿态"。**

- 人脸识别（FaceNet）：需要认识这张脸是谁 → 依赖个人特征 → 10 人不够
- 专注度检测（GazeNet）：只需要判断眼神往哪看 → 依赖通用生物信号 → 10 人基本够

专注/不专注的信号是通用的：
- 眼神偏离屏幕 → 不专注（通用信号）
- 头部大幅转动 → 不专注（通用信号）
- 长时间不眨眼 → 可能疲劳（通用信号）

这些信号不依赖特定的脸型或肤色。

## 五、风险和缓解措施

### 风险 1：VLM 对"发呆 vs 安静学习"判断不准

**风险等级：** 🟠 高

**描述：** AI 无法区分"认真思考但没动"和"发呆"，这两者看起来一模一样。

**缓解：**
1. 主动学习：只挑 AI 最不确定的帧让人工审
2. HMM 平滑：连续 5 秒的"发呆"才会被判为不专注，单帧不准
3. 时序窗口：用连续 N 帧的 gaze 方向变化来判断，而不是单帧

---

### 风险 2：10 人数据换设备后准确率崩溃

**风险等级：** 🟠 高

**描述：** 不同手机的摄像头参数、光照、色温完全不同，模型会过拟合录制设备。

**缓解：**
1. 个人校准：用户首次使用做 30 秒校准
2. 用户使用中学习：用无标签数据持续适应
3. 数据增强：模拟不同摄像头的效果（加噪声/模糊/色彩偏移）

---

### 风险 3：MediaPipe 在某些手机上检测失败

**风险等级：** 🟡 中

**描述：** 低端华为手机的前置摄像头或 MediaPipe 在暗光下检测置信度低。

**缓解：**
1. 检测置信度 < 0.7 的帧直接丢弃
2. 回退策略：置信度低的帧，用前后的帧插值
3. 华为 Camera Kit 作为补充（如果有硬件支持）

## 六、下一步行动

### Week 1 必须做的事（验证可行性）

**Day 1-2：搭环境**

```bash
# 1. 安装 FFmpeg
sudo apt install ffmpeg

# 2. 安装 Python 依赖
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install mediapipe opencv-python pandas numpy pillow tqdm
pip install "llava[all]==1.0.0"  # LLaVA

# 3. 下载 LLaVA 模型（7B INT4 版，约 4GB）
# huggingface-cli download llava-1.6-mistral-7b-ggml --filename ggml-model-q4_k.gguf
```

**Day 3-4：录制 10 小时测试数据**

- 找 3 个人（最好不同脸型/肤色/眼镜情况）
- 每人录制 3-4 小时学习视频
- 包含专注、不专注、光照变化等场景

**Day 5-7：验证 AI 标注准确率**

- 从 10h 数据中随机抽 500 帧
- 人工标注（3 人独立标注，取多数票）
- 测试 VLM 准确率
- 如果 VLM 准确率 < 60%，需要重新设计 prompt 或换模型

**验收标准：**
- VLM 准确率 ≥ 65% → 继续
- VLM 准确率 < 60% → 调整方案
